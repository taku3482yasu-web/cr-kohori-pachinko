# CRこおりくん パチンコ

スロット版「CRこおりくんの大冒険 ～おにおにの野望～」（`my-project/koori/`）をもとにしたパチンコゲーム。
キャラクター・ドット絵・背景と、ふるカワの会話だけをスロット版から持ってきて、演出・オープニング・エンディングは新しく作る。

## 遊び方

- `index.html` をブラウザで直接開く（サーバー不要）
- ハンドルを押している間、玉を発射する（**Space** でも）。押したまま回す・**← →** キー・ホイールで強さを変える（Shift+← → で 10 ずつ）
- 「← 左打ち」「右打ち →」で、それぞれに向いた強さに合わせる（`config.launch.presets`）
- 持ち玉がなくなったら「玉貸し」（+125発）
- `js/config.js` の `debug: true` で、画面下にデバッグパネル（電チュー・アタッカーの開け閉め、オート発射、集計）が出る

## ユーザーが決めたこと（2026-10-19）

- スロット版から持ってくるもの: キャラ・ドット絵・背景（`sprites.js` `characters.js` `backgrounds.js` をコピー）、ふるカワの会話

## 盤面（段階1）

| 部品 | 場所 | 内容 |
|---|---|---|
| 外レール・内レール | 左下 → 上 → 右下 | 発射した玉は2本のレールの間を上り、強さに応じて盤面の左〜右に落ちる。弱くて戻ってきた玉はファール（持ち玉に戻る） |
| 返しゴム | 右上 | 外レールを回り切った強い玉を右打ちの通り道へ跳ね返す |
| 液晶の枠 | 中央 | 山形の屋根。平らだと玉が乗ったまま止まるため |
| ワープ | 液晶の左 | 枠のほうへ動いている玉だけ入り、液晶の下のステージへ出る |
| ステージ | 液晶の下 | 中央の切れ目から落ちるとヘソのほぼ真上。床の低いところの穴からは手前にこぼれる |
| 風車 | 左 | 一定の速さで回る4枚羽根 |
| 道釘 | 左下 → ヘソ | 玉を転がしてヘソへ寄せる釘の列 |
| ヘソ（START） | 中央下 | 両脇の柱（命釘）のすき間 6.8（玉の直径は 6） |
| ゲート | 右打ち | 通り抜けると反応する（普図の抽選は段階2） |
| 電チュー | 右打ち | 閉じているときはふた。開くと羽根が外へ開いて玉を拾う |
| アタッカー | 右打ちの下 | 閉じているときは左に傾いたふた。開くと幅 60 の入口 |
| 一般入賞口 | 左下・中央下 | 賞球 10 |

### 物理のしくみ（`js/physics.js`）

- 1/60 秒を 10 回に分けて計算する。玉は円、当たる相手は「円（釘・柱）」と「線分（レール・壁・ふた）」の2種類だけ
- 面ごとに跳ね返り（restitution）と、面に沿った速さの残り（friction）を変える（`config.ball.surfaces`）。レール・壁は玉が沿って転がるので friction をほぼ 1 にしている
- 釘に当たると少しだけ速さをゆらす（`jitter`）。ほとんど止まった玉は軽くゆらし（`stall`）、3秒止まったままならアウトにする
- 釘は `config.board.nails` の並び（grid / line / points）から作る。レール・枠・ガイド・ほかの釘とのすき間が「玉の直径より少しだけ狭い」と玉がはさまって止まるので、近すぎる釘は自動で打たない
- 玉どうしはぶつからない（盤面で玉が混み合うことが少ないので省いた）

### 打ち出しの強さと入り方（`tools/test.html`、強さごとに 200 発）

| 強さ | 結果 |
|---|---|
| 0〜20 | ほぼファール |
| 30（左打ち） | ヘソ 5.5%（250発あたり約14回）、ワープ 16% |
| 40〜70 | 液晶の右に流れる玉が増え、右打ちの通り道にも入りはじめる |
| 90〜100（右打ち） | ゲートを 100% 通る。電チューが開いていれば約 6 割が電チューへ、アタッカーが開いていれば残りの大半がアタッカーへ |

回転率（ヘソの入りやすさ）は段階2でスペックを決めてから合わせる。

## 確認用のツール

| ファイル | 内容 |
|---|---|
| `tools/test.html` | 盤面テスト。強さ 0〜100 で玉を打ち、ファール・ヘソ・ゲート・電チュー・アタッカー・ワープなどの割合を表で出す。止まった玉の位置も出す。`?balls=500` `?open=0` `?seed=1` |
| `tools/trace.html` | 玉の通り道を盤面の上に線で描く（黄: 入賞 / 赤: アウト / 灰: ファール / 紫: 止まった）。`?strength=45&balls=30&open=1` |
| `tools/phone.html` | `index.html` をスマホの大きさ（390x844）で表示する |
| `tools/run-test.sh` | `test.html` をヘッドレスChromeで動かして結果を表示する（`sh tools/run-test.sh "balls=200"`） |
| `tools/shot.sh` | ページをヘッドレスChromeで画像にする（`sh tools/shot.sh "index.html?auto=1&strength=30&skip=60" out.png 1100,900`） |

- `index.html?auto=1&strength=30` で開くとすぐ自動で打ちはじめる。`&skip=60` で 60 秒ぶん早送りしてから表示する（ヘッドレスChromeでは時間が進まないため）
