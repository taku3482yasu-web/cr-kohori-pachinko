# Pこおりくん ～内定ツラヌキ物語～

スロット版「CRこおりくんの大冒険 ～おにおにの野望～」（`my-project/koori/`）をもとにしたパチンコゲーム。
キャラクター・ドット絵・背景と、ふるカワの会話だけをスロット版から持ってきて、演出・オープニング・エンディングは新しく作る。

## 遊び方

- `index.html` をブラウザで直接開く（サーバー不要）
- はじめに「台選び」でスペック（1/99・1/159）を選ぶ。右上の「台選び」でいつでも選び直せる（持ち玉ははじめに戻る）
- 通常時は左打ちでヘソを狙う。大当たり・時短（RUSH）・小当たりのあいだは「右打ち →」が出るので右打ちにする
- ハンドルを押している間、玉を発射する（**Space** でも）。押したまま回す・**← →** キー・ホイールで強さを変える（Shift+← → で 10 ずつ）
- 「← 左打ち」「右打ち →」で、それぞれに向いた強さに合わせる（`config.launch.presets`）
- 持ち玉がなくなったら「玉貸し」（+125発）
- `js/config.js` の `debug: true` で、画面下にデバッグパネル（釘の調整の表示、次の保留を大当たり・小当たりにする、時短に入る、オート発射、オートで打ち分け、集計）が出る

### スペック（2026-10-19 ユーザー指定。1/199・1/319 から 1/99・1/159 に変更）

ゲームを始める前に 1/99 と 1/159 を切り替えられる。アタッカーの賞球は 15（ユーザー指定）。

| | 1/99 | 1/159 |
|---|---|---|
| 初当たり（特図1・ヘソ） | 50%: 200個（時短なし → 通常時）/ 50%: 200個 + 突破チャレンジ | 25%: 300個（時短なし）/ 75%: 300個 + 突破チャレンジ |
| 突破チャレンジ | 突破率 約50% | 突破率 約50% |
| RUSH 中の大当たり | 50%: 200個 / 50%: 900個 | 100%: 1300個 |
| RUSH 継続率 | 約79% | 約80% |
| 時短の回数（突破チャレンジ / RUSH） | 1回 / 6回 | 1回 / 6回 |
| 小当たり（特図2） | 1/8 | 1/7.7 |
| 小当たり（突破チャレンジ中） | 1/6.7 | 1/6.7 |

- 出玉とラウンド: 賞球 15 なので 1ラウンド 10カウント = 150個。200個 は 2R × 7C = 210個、300個 = 2R、900個 = 6R、1300個 は 9R × 10C = 1350個（200・1300 はちょうどにならないので近い値。画面には 200個・1300個 と出す）
- 流れ: 初当たりで時短ありなら **突破チャレンジ**（時短 1回 + 残り保留）。そこで当たれば **RUSH 突入**。RUSH 中は大当たりのたびに時短 6回
- RUSH の仕組みは両方とも同じ: 時短中は電サポ（ゲートの普図がほぼ当たり、電チューがよく開く）。電チューに入った玉で特図2 を抽選し、小当たりでアタッカーが 1.8秒開く。そこへ玉が入ると V入賞 → 大当たり。特図2 で大当たりを直接引くこともある
- 時短が終わっても、残っている特図2 の保留で小当たりを引けば続く（残り保留もなくなったら終わり）
- 突破率・継続率は時短の回数と小当たりの確率で決まる。`tools/simulate.html` で測って合わせた（`?cs=1&rs=6` で時短の回数を変えて測れる）
- 小当たりのアタッカーは **V に入るまで開いている**（最大 8秒）。右打ちを続けていれば V入賞率は 100%（前は 1.8秒だけ開いて約93% だったが、ブラックアウトなどで「当たり」と見せたあとに V に入らず突破失敗になることがあったので直した。2026-10-19）
- 保留は特図1・特図2 それぞれ 4 個まで。特図2 を先に消化する。結果は玉が入ったときに決める（先読み演出に使う）

### 保留

- **先読みの量**はカスタマイズで選ぶ（なし / チャンス 30% / おすすめ 50% / 熱 90%。`show.senyomi`）。当たりの保留は占有率で「先読みを出すか」を1回だけ決め、出すなら必ず色が付き、ボタン・高確率ステージもその中で出る
- 赤保留は期待度を上げた（ユーザー指定。外れで出る重みを 5 → 1.7）
- **占有率が高いほどガセ（外れのときの先読み）が少ない**（ユーザー指定）。ガセの量は チャンス 1 / おすすめ 0.6 / 熱 0.3（Claude が決めた）。なので先読みが出たときの信頼度は熱ほど高い。1/99 設定3 で測った、出たら当たる割合（チャンス / おすすめ / 熱）:

  | 演出 | チャンス | おすすめ | 熱 |
  |---|---|---|---|
  | 赤保留 | 36% | 57% | 82% |
  | ボタン（先読み） | 34% | 58% | 82% |
  | 入賞時の音＋赤いボタン | 41% | 54% | 69% |
  | SE城前・満月へ | 31% | 51% | 80% |
  | 虹保留 | 100% | 100% | 100% |

- **入賞時の音**（ユーザー指定）: ヘソに入ったときに、ユーザーが録音した音（`sounds/heso.m4a`）が鳴って台のボタンが赤く光る。大当たりのうち 60% で鳴る（占有率 60%。測定 59〜61%）。録音の2つの音のうち長いほう（1.3〜3.5秒。ユーザー指定）を 4倍の音量で鳴らす（`show.voice`）。ファイルを直接開いても鳴るように `js/sound-heso.js` に埋め込んである（録音を差しかえたら `python tools/embed-sound.py`）
- **保留変化**（ユーザー指定）: 色が付く保留の 約4割は、最初は白で出て「ピキーン！」と本来の色に変わる。変わるのは、その保留の変動が始まるとき（当該変化）か、ほかの変動が始まって保留が1つ進むとき（半々。Claude が決めた）
- こおりくんの体の形。期待度は低い順に 白 → 青 → 緑 → 紫 → 赤 → 虹。**虹は大当たり確定**（ユーザー指定。白がふつうの保留）
- 色は玉がヘソに入ったときに決まる（`holdColors.hit` / `holdColors.miss` の重み）
- 変動中の保留（当該保留）は液晶の下の真ん中に大きく出る

### 台のボタン（こおりくんの体の形）

- ヘソに入ったときに **赤く光る / ぶるぶる震える（スマホは本体も振動）/ 高い音が鳴る** のどれかが起きることがある。起きたらその保留の当たりの確率は **約60%**（ユーザー指定）
- 当たりの保留で起きる確率（`button.hitRate`）だけを決めておき、外れで起きる確率は「起きたときに 60%」になるよう、スペックの大当たり確率から自動で計算する
- バトルの最後に「PUSH!」が出たら押す（B キーでも）。押さなくてもそのまま進む

### 変動の流れ（特図1）

1. 図柄が回る
2. **チャレンジ**（こおりくんの宝探し / おかがっぱのミュージックチャレンジ / シバターのプロレスチャレンジ / おにおにの特訓 / ともいしのお弁当作りチャレンジ）。ゲージがたまり切れば成功。ミュージック・プロレスは 2026-10-19 にユーザー指定で追加
3. 成功すると左右の図柄がそろって **リーチ** → **バトル**。失敗なら図柄がばらばらに止まる
4. バトルで撃破すると図柄がそろう（大当たり）。負けると中の図柄がずれて止まる

- 当たりは必ず チャレンジ → 成功 → 撃破
- バトルの相手と成功率（ユーザー指定の順。数値はおにおに 80%・ナイナイ確定がユーザー指定、ほかは Claude が決めた）:

  | 相手 | 成功率 |
  |---|---|
  | おかがっぱ | 約5% |
  | ひびきまくり | 約20% |
  | おにおに | 80% |
  | シーシャ・ナイテイ・ナイナイ | 確定 |

  当たりのときの相手の重み（`battles.*.hit`）を決めておき、外れのときの重みは成功率を守るよう自動で計算する（`Scenario.missBattleMass`）
- チャレンジの種類の熱さ（Claude が決めた）: 宝探し < ミュージック < プロレス < 特訓 < お弁当作り（1/99 で成功率 45% / 46% / 49% / 53% / 66%）
- 外れの変動時間: 保留の数（変動中のものを含めて 1〜4）ごとに 6 / 3.5 / 2 / 1秒（高い設定でもよく回るように）。チャレンジ失敗: 10.5秒。リーチ: 23.5秒
- 特図2（突破チャレンジ・RASH 中）の演出は段階4（下）

### 通常時のステージ（背景。2026-10-19 ユーザー指定）

- 30回転ごと（`stages.interval`。回数は Claude が決めた）に 通学路 → 小倉駅 → 遠賀川 → ゲームセンター → 石の川 → 通学路… と変わる。小倉駅・ゲームセンター・石の川・満月の背景はパチンコ版で新しく描いた
- **高確率ステージ**: 当たりの見込みが高い保留があると、SE城前 か 満月 に移ることがある（「チャンス！」と出る）。その保留を消化したら元のステージに戻る。移ったら当たり 約50%（`stages.hi`）
- **すぐ変わる（当たり濃厚）**: ステージが変わってから 5回転以内に当たりの保留があれば、約50% ですぐ次のステージに変わる（ユーザー指定）。外れでは起きない
  - 外れの保留は、ステージが変わってから 5回転のあいだは高確率ステージにも移らない（濃厚の合図とまぎらわしくならないように。Claude が決めた）
  - 「すぐ変わる」は通学路〜石の川の切り替えのこと。高確率ステージから元に戻るのは数えない
- 測った結果（1/99・1/159）: すぐ変わったら当たり 100% / 100%、高確率ステージに移ったら当たり 53.2% / 54.3%

### ふるカワ

- 通常時、変動の始まりにしゃべることがある。熱い変動ほど出やすく、吹き出しの文字の色が上がる（白 → 青 → 緑 → 紫 → 赤 → 金 → 虹）
- 赤以上はチャンスのセリフ、それ以外は期待のセリフやキャラクターの話（スロット版のセリフ）
- **豆知識**（ユーザー指定）: 色が白・青のときは 4割で、このゲームのヒントを教えてくれる（「豆知識：虹色の保留は当たり確定だよ！」など。`furukawa.hintLines`）
- バトルの相手が出てきたときに返事、撃破したときにひとこと

## 突破チャレンジと RASH（段階4。2026-10-19 ユーザー指定）

数値は `config.show.challengeBattle` / `rash` / `kooriRash` / `onioniRash` / `rashButton`。描くのは `js/lcd-rash.js`（こおりRASH のバトルは `js/lcd.js`）。

### 突破チャレンジ（おにおにとのバトル）

- 初当たりで時短ありなら突破チャレンジ。電チューの保留が 4 個たまると（15秒たっても 4 個にならなければその時点の保留で）おにおにとのバトルが始まる（ユーザー指定）
- バトルが始まったら電サポは終わり、たまった保留で勝負する。保留 1 つが 1 ラウンドで、どこかで当たれば **突破**（RASH 突入）
- 保留ごとにこおりくんの武器が変わる。期待度の低い順に **素手 → ハルキソード → ハルキハンマー → おにおに絶対殺す剣（確定）**（ユーザー指定）
- 途中のラウンドはおにおにに受け止められる（ガキン！）。決着のラウンドは「PUSH!」のあと最後の一撃
- 突破率は突破チャレンジ中の小当たりの確率（`challengeSmallRate` 1/6.7）で 50% に合わせた

### RASH（こおりRASH / おにおにRASH）

- RASH 突入の大当たり中に「こおりRASH！」「おにおにRASH！」を選ぶ（ユーザー指定。画面の右のボタン、または 1 / 2 キー。選ばなければこおりRASH）
- 表示の名前は RUSH → **RASH** にした（ユーザーの書き方に合わせた）
- **こおりRASH**: バトル演出がメイン。当たりの保留と、最後の保留（このあと時短も保留もない）は必ずバトル。外れでもときどき（相手の成功率を守る割合で）バトルになる。バトルに勝てば当たり
  - 相手（成功率の低い順。ゴールド金面犬は確定がユーザー指定、ほかの数値は Claude が決めた）: シバター 約15% / Mr.SASAKI 約35% / おにおに 約70% / ゴールド金面犬 確定
- **おにおにRASH**: 真ん中でおにおにが椅子に座って眠っている。開眼すれば当たり。当たるときだけ違和感が起きる（外れでは何も起きないので、違和感があれば当たり）
  - そのまま開眼 / おにおにが虹色 / 画面が反転 / 白黒 / 顔がドアップになって開眼（ユーザー指定）

### ブラックアウト・RASH の継続・切り替え（2026-10-19 ユーザー指定）

- **ブラックアウト**（突発当たり。こおりRASH・おにおにRASH 共通。RASH に入ってからだけ。突破チャレンジ中は出ない）: RASH 中の当たりの一部（`blackout.rate` 12%。割合は Claude が決めた）で、前ぶれなく暗転 → 虹色のこおりくんが出てくる → 「当たり」が虹色の文字で1文字ずつ → 「こおりがいただいた！」で虹色にフラッシュ。突発なので、ふるカワはしゃべらない
- **大当たりのあと**: 出玉を取り終わったら「〇回目」を大きく出してから「〇〇RASH 継続！」

### 物理のしくみ（`js/physics.js`）

- 1/60 秒を 10 回に分けて計算する。玉は円、当たる相手は「円（釘・柱）」と「線分（レール・壁・ふた）」の2種類だけ
- 面ごとに跳ね返り（restitution）と、面に沿った速さの残り（friction）を変える（`config.ball.surfaces`）。レール・壁は玉が沿って転がるので friction をほぼ 1 にしている
- 釘に当たると少しだけ速さをゆらす（`jitter`）。ほとんど止まった玉は軽くゆらし（`stall`）、3秒止まったままならアウトにする
- 釘は `config.board.nails` の並び（grid / line / points）から作る。レール・枠・ガイド・ほかの釘とのすき間が「玉の直径より少しだけ狭い」と玉がはさまって止まるので、近すぎる釘は自動で打たない
- 玉どうしはぶつからない（盤面で玉が混み合うことが少ないので省いた）

### 打ち出しの強さと入り方（`tools/test.html`、強さごとに 200 発）

| 強さ | 結果 |
|---|---|
| 0〜20 | ほぼファール |
| 30（左打ち） | ヘソ 5.5%（250発あたり約14回）、ワープ 16% |
| 40〜70 | 液晶の右に流れる玉が増え、右打ちの通り道にも入りはじめる |
| 90〜100（右打ち） | ゲートを 100% 通る。電チューが開いていれば約 6 割が電チューへ、アタッカーが開いていれば残りの大半がアタッカーへ |

回転率（ヘソの入りやすさ）は段階2でスペックを決めてから合わせる。
