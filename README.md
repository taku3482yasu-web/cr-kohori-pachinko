# Pこおりくん ～内定ツラヌキ物語～

スロット版「CRこおりくんの大冒険 ～おにおにの野望～」（`my-project/koori/`）をもとにしたパチンコゲーム。
キャラクター・ドット絵・背景と、ふるカワの会話だけをスロット版から持ってきて、演出・オープニング・エンディングは新しく作る。

## 遊び方

- `index.html` をブラウザで直接開く（サーバー不要）
- はじめに「台選び」でスペック（1/99・1/159）を選ぶ。右上の「台選び」でいつでも選び直せる（持ち玉ははじめに戻る）
- **前回の続き**（2026-10-19 ユーザー指定）: 遊んでいるあいだ約3秒ごとと、ページを閉じるときに、このブラウザに保存する（`js/save.js`）。次に開いたときに「前回から続ける / 新しく始める」を選ぶ。続けるときはオープニングを出さず「CONTINUE!」。スペック・設定・持ち玉・集計・保留・RASH や大当たりの途中まで戻る（盤面を飛んでいる途中の玉は持ち玉に戻す）。URL で台を決めたとき（`?spec=`、確認用）は保存しない
- 右側の「回転数」「回転率」は、突破チャレンジ・RASH が終わったら 0 から数え直す（2026-10-19 ユーザー指定）
- 通常時は左打ちでヘソを狙う。大当たり・時短（RUSH）・小当たりのあいだは「右打ち →」が出るので右打ちにする
- **発射ボタン**（2026-10-20 ユーザー指定）: タップで発射をはじめ、もう一度タップで止める（`game.fireOn`）。ハンドルを押している間・**Space** でも発射する。窓（データ・図鑑など）を開いたら止める
- **強さのゲージ**（2026-10-20 ユーザー指定）: いまの強さの数字と「左打ち / 右打ち」、左打ち・右打ちに向いた強さ（`config.launch.presets`）の印。動かして強さを変えられる。スマホではハンドルを出さず、ゲージと発射ボタンで操作する（ハンドルは指で強さが隠れるため）
- ハンドル: 押している間発射。押したまま回したぶんだけ強さが変わる（触っただけでは変わらない。前は触った場所の角度で強さが決まり、「左打ち」「右打ち」で合わせた強さが押した瞬間に変わっていた）。**← →** キー・ホイールでも強さを変える（Shift+← → で 10 ずつ）
- 「← 左打ち」「右打ち →」で、それぞれに向いた強さに合わせる（`config.launch.presets`）。いまの強さに近いほうのボタンが光る。カスタマイズの「打ち分け: 自動」（`autoAim`）にすると、台の状態が変わったときに自動で合わせる
- 持ち玉がなくなったら「玉貸し」（+125発）
- `js/config.js` の `debug: true` で、画面下にデバッグパネル（釘の調整の表示、次の保留を大当たり・小当たりにする、時短に入る、オート発射、オートで打ち分け、集計）が出る

- **V への昇格**（2026-10-20 ユーザー指定）: 小当たり（V入賞の当たり）の `show.promote.vRate`（50%。Claude が決めた）は V 以外の図柄（出玉の振り分けで奇数・偶数）で3つそろえて見せ、V入賞の大当たりの1ラウンド目の始め（`vDelay` 0.3秒後）に V 図柄に昇格する（「V 昇格！」）。出玉は変わらないので、奇数への昇格と違って「〇個」は隠さない（`bonusStart` の `promoteV`）。`tools/lcd.html?force=koori&vpromote=1`
- 出玉とラウンド: 賞球 15 なので 1ラウンド 10カウント = 150個。200個 は 2R × 7C = 210個、300個 = 2R、900個 = 6R、1300個 は 9R × 10C = 1350個（200・1300 はちょうどにならないので近い値。画面には 200個・1300個 と出す）
- 流れ: 初当たりで時短ありなら **突破チャレンジ**（時短 1回 + 残り保留）。そこで当たれば **RUSH 突入**。RUSH 中は大当たりのたびに時短 6回
- RUSH の仕組みは両方とも同じ: 時短中は電サポ（ゲートの普図がほぼ当たり、電チューがよく開く）。電チューに入った玉で特図2 を抽選し、小当たりでアタッカーが開く（V に入るまで、最大 20秒）。そこへ玉が入ると V入賞 → 大当たり。特図2 で大当たりを直接引くこともある
- 時短が終わっても、残っている特図2 の保留で小当たりを引けば続く（残り保留もなくなったら終わり）

### 変動の流れ（特図1）

1. 図柄が回る
2. **チャレンジ**（こおりくんの宝探し / おかがっぱのミュージックチャレンジ / シバターのプロレスチャレンジ / おにおにの特訓 / ともいしのお弁当作りチャレンジ）。ゲージがたまり切れば成功。ミュージック・プロレスは 2026-10-19 にユーザー指定で追加
3. 成功すると左右の図柄がそろって **リーチ** → **バトル**。失敗なら図柄がばらばらに止まる
4. バトルで撃破すると図柄がそろう（大当たり）。負けると中の図柄がずれて止まる

- 当たりは必ず チャレンジ → 成功 → 撃破
- バトルの相手と成功率（ユーザー指定の順。数値はおにおに 80%・ナイナイ確定がユーザー指定、ほかは Claude が決めた）:

  | 相手 | 成功率 |
  |---|---|
  | おかがっぱ | 約5% |
  | ひびきまくり | 約20% |
  | おにおに | 80% |

### 通常時のステージ（背景。2026-10-19 ユーザー指定）

- 30回転ごと（`stages.interval`。回数は Claude が決めた）に 通学路 → 小倉駅 → 遠賀川 → ゲームセンター → 石の川 → 通学路… と変わる。小倉駅・ゲームセンター・石の川・満月の背景はパチンコ版で新しく描いた
- **高確率ステージ**: 当たりの見込みが高い保留があると、SE城前 か 満月 に移ることがある（「チャンス！」と出る）。その保留を消化したら、次の通常ステージへ進む（2026-10-20 ユーザー指定。前は元のステージに戻っていた。`Scenario.endStage`。「ステージ: ○○」と出る）。SE城前・満月はそれぞれの BGM になる。移ったら当たり 約50%（`stages.hi`）
- **すぐ変わる（当たり濃厚）**: ステージが変わってから 5回転以内に当たりの保留があれば、約50% ですぐ次のステージに変わる（ユーザー指定）。外れでは起きない
  - 外れの保留は、ステージが変わってから 5回転のあいだは高確率ステージにも移らない（濃厚の合図とまぎらわしくならないように。Claude が決めた）
  - 「すぐ変わる」は通学路〜石の川の切り替えのこと。高確率ステージから次のステージに進むのは数えない
- 測った結果（1/99・1/159）: すぐ変わったら当たり 100% / 100%、高確率ステージに移ったら当たり 53.2% / 54.3%

## 突破チャレンジと RASH（段階4。2026-10-19 ユーザー指定）

### 突破チャレンジ（おにおにとのバトル）

- 初当たりで時短ありなら突破チャレンジ。電チューの保留が 4 個たまると（15秒たっても 4 個にならなければその時点の保留で）おにおにとのバトルが始まる（ユーザー指定）
- バトルが始まったら電サポは終わり、たまった保留で勝負する。保留 1 つが 1 ラウンドで、どこかで当たれば **突破**（RASH 突入）
- 保留ごとにこおりくんの武器が変わる。期待度の低い順に **素手 → ハルキソード → ハルキハンマー → おにおに絶対殺す剣（確定）**（ユーザー指定）

- 突破率は突破チャレンジ中の小当たりの確率（`challengeSmallRate` 1/6.7）で 50% に合わせた
- **おまけ**（2026-10-19 ユーザー指定）: バトルが始まってから電チューに入った保留（電チューの開き残り・飛んでいた玉）は、見た目では保留を増やさない（保留のアイコン・入賞の音・ボタンを出さない。`result.extra`）。4回の勝負で突破できなかったら、決着のあとに「もうひとつおまけに！」→ 最後の一撃（PUSH）→ 結果で、その保留の結果を見せる（`cextra → cfinal → cresult`。`challengeBattle.timing.extra`）。途中で突破したときは、RASH の保留としてそのまま残る
  - 前は、この保留がバトルのあとに こおりRASH のバトルの演出で消化されて、突破チャレンジが続いているように見えていた
  - `tools/lcd.html?force=challenge&win=-1&extra=hit`（`extra=miss` で外れ）で確認できる

### 物理のしくみ（`js/physics.js`）

- 1/60 秒を 10 回に分けて計算する。玉は円、当たる相手は「円（釘・柱）」と「線分（レール・壁・ふた）」の2種類だけ
- 面ごとに跳ね返り（restitution）と、面に沿った速さの残り（friction）を変える（`config.ball.surfaces`）。レール・壁は玉が沿って転がるので friction をほぼ 1 にしている
- 釘に当たると少しだけ速さをゆらす（`jitter`）。ほとんど止まった玉は軽くゆらし（`stall`）、3秒止まったままならアウトにする
- 釘は `config.board.nails` の並び（grid / line / points）から作る。レール・枠・ガイド・ほかの釘とのすき間が「玉の直径より少しだけ狭い」と玉がはさまって止まるので、近すぎる釘は自動で打たない
- 玉どうしはぶつからない（盤面で玉が混み合うことが少ないので省いた）
